Program Setup and Configuration

This guide walks administrators through the core setup of a school program, covering basic contact information, registration rules, integrated payment gateways, fee structures, and system branding.

By MAC Administration Last updated:

Accessing Program Details

To manage the foundational settings of your school programs, navigate to the left-hand menu, expand Projects Setup, and select Schools. From there, open the specific program to view the Program Detail dashboard.

The dashboard is divided into three main tabs: About, Registration, and Files. Click the blue Edit button in the top right corner of the page to make changes to any of these sections.

Figure 1: Program Detail dashboard showing the primary configuration tabs and edit controls.

1. The About Tab: Core Program Information

The About tab houses the general identifying information and external linkages for the program.

Program Details

This section defines the program's identity, including the Program Name (e.g., BostonFulltimeSchool), Program Type, District, and short or long descriptions. You can also view the program's "Active" status and whether it is flagged as a "Test School".

Contact Details

Here you can manage the program's public-facing contact information. This includes the primary contact name, phone number, email, physical address, and links to social media (Facebook, Twitter), the website, and the Students and Parents Handbook.

External Linkage

This section stores backend financial and administrative codes, such as the External bank account number, Cost center code, and E-transfer email.

2. The Registration Tab: Enrollment, Fees, and Payment Configuration

The Registration tab serves as the central control panel for managing enrollment parameters, academic structures, fee schedules, and integrated payment gateways.

Registration Details

This section controls core enrollment parameters:

  • Age & Dates: Set the Lower and Upper age limits, Start and End dates, Start and End times, and Cutoff dates.
  • Fees: Establish core costs, including the Application fee, Returning application fee, Program fee, and Waitlist fee.
  • Toggles: Activate essential registration flows by checking boxes for Automatic WaitlistFee, Future Waitlist, New/Returning Filter, Allow Registration, and restricting to returning students only.
  • Level Details: Manage academic structure by checking boxes to activate "Levels" and determining if they are mandatory or if multiple levels are allowed.

Payment & Financial Configuration

Manage how families submit online payments and contributions directly through the portal:

  • Donation Details: Toggle donations to active and set a default Donation Amount to prompt voluntary contributions during checkout.
  • Stripe Details: Configure your payment gateway by inputting the required Stripe Publish Key and Stripe Secret Key.
  • EFT Bank Withdrawal Details: Set up electronic fund transfers by toggling EFT Bank Withdrawal to active, defining the Withdrawal Frequency (e.g., Monthly), setting the number of Withdrawal Instalments, and specifying the Instalment Amount.

Carry Over

Manage code transmittals using the Carry over codes utility to transfer configurations or tracking codes smoothly across terms or academic sessions.

Other Controls

Use the Export Re-Enrolments button to download a comprehensive record of returning students for the upcoming term.

Figure 2: Registration tab interface showing enrollment rules, fees, and payment gateway fields.

3. The Files Tab: Branding

The Files tab is used to manage the visual assets associated with your school program.

Image Uploads: Administrators can view and manage the current Image path, Catalog Image path, and logo Image path. Uploading a logo ensures your specific school's branding appears correctly across the system.

Frequently Asked Questions (FAQ)

  • What if I need to temporarily pause new registrations?
    Navigate to the Registration tab and uncheck the Allow Registration box under the Registration Details section. This acts as a master switch to stop incoming applications.
  • What if our school updates its primary contact email or phone number?
    Navigate to the About tab and update the fields under the Contact Details section, such as the Contact number or Contact email, to ensure parents have the correct information.
  • Where do I input our Stripe keys for online payments?
    Stripe configuration is managed on the Registration tab. Scroll down to the Payment & Financial Configuration section to input your Stripe Publish Key and Stripe Secret Key.
  • Can I set different application fees for new versus returning students?
    Yes. On the Registration tab, you can set distinct amounts in the "Application fee" field and the "Returning application fee" field.
