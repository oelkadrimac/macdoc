Codes

Organize and maintain system codes for various operations.

By MAC Administration Last updated:

The Codes section is a critical administrative tool used to build and organize the foundational categories for your school's structural and academic data. To access this area, navigate to the left-hand menu, expand the Administration module, and select Codes. From here, you can navigate through various tabs to configure different data points.

General Navigation: Creating New Entries

All tabs within the Codes section (Grades, Subjects, Sections, Periods, Rooms, Years, Levels, and Documents) function similarly and feature the option to create a new instance.

To add a new entry to any category:

  • Navigate to the desired category tab.
  • Click the blue + icon located in the top right corner of the screen.
  • A right-hand side panel will open specific to that tab (e.g., clicking + on the Grades tab opens a "New Grade" panel).
  • Fill in the required information. Ensure all mandatory fields (marked with a red asterisk *) are filled out. If a required field is left blank, the system will highlight it in red and display an error message (e.g., "Name is required").
  • Click Save to add the entry to the system, or Cancel to discard the action.

Existing entries will populate in a table format within each tab. You can use the pencil icon to Edit or the trash can icon to Delete an existing code directly from the list.

Category Configurations

1. Grades

Use this tab to define the specific grade levels available at your center.

  • Name*: Enter the standard name of the grade (e.g., bostonGrade01).
  • Level*: Select the corresponding academic level from the dropdown menu.
  • Salesperson Code*: Click the dropdown to search and select the specific financial/administrative tracking code associated with this grade (e.g., OGSS-G10-B).

2. Subjects

Use this tab to organize the academic subjects or courses offered.

  • Name*: Enter the general name of the subject.
  • Code*: Assign a unique internal identification code for the subject.
  • Title: Provide the formal title of the subject.
  • Description: Add any relevant details about the curriculum or subject focus.
  • Hours: Input the total number of credit or instructional hours associated with the subject.

3. Sections

Use this tab to create subsets within grades or classes (such as organizing a large grade into Section A and Section B).

  • Name*: Enter the distinct name or identifier for the section.

4. Periods

Use this tab to define the daily bell schedule or instructional time blocks.

  • Name*: Enter the label for the period (e.g., bostonPeriod01).
  • Description: Add a brief description if necessary.
  • Start: Input the period's start time in HH:MM format and specify AM or PM.
  • End: Input the period's end time in HH:MM format and specify AM or PM.

5. Rooms

Use this tab to log the physical classrooms or facilities available in your center.

  • Number*: Enter the room number or identifying name (e.g., bostonRoom01).

6. Years

Use this tab to define the active academic years for enrollment and historical tracking.

  • Year*: Select the relevant year from the provided dropdown menu (e.g., 2024, 2025, 2026).

7. Levels

Use this tab to create structured administrative tiers. As noted in the system demo, Levels act as a precursor to formal grades. Depending on how your specific school functions, the levels defined here can later be toggled as a mandatory selection step for parents during the project and registration setup.

  • Name*: Enter the identifier for the level.
  • Description: Add relevant details summarizing the level.
  • Minimum Age*: Define the youngest age permitted for this level.
  • Maximum Age*: Define the oldest age permitted for this level.
  • Level Fee: Set the base dollar amount charged for enrollment in this level.
  • Grade*: Link this level to its corresponding academic grade using the dropdown menu.
  • Inactive Checkbox: Check this box to archive or disable the level without permanently deleting it.

8. Documents

Use this tab to manage the mandatory or optional paperwork that students must provide during the registration process.

  • Documents Name*: Enter the title of the required form or document.
  • Document Template: Click the Browse to upload button to attach a downloadable template for parents/students to fill out.
  • Documents Description: Provide instructions or details about what the document entails.
  • New User: Toggle between Required and Not Required to dictate if first-time registrants must submit this file.
  • Returning User: Toggle between Required and Not Required to dictate if existing students must re-submit this file.
  • Inactive Checkbox: Check this box to disable the document requirement without deleting it from the system.
