MACSIS Administration Guide: Staff and Classes

This guide provides administrators with comprehensive, step-by-step instructions for onboarding personnel, and managing classroom rosters.

By MAC Administration Last updated:

1. Managing Staff Profiles

The Staff module acts as the central directory for all teachers, administrators, and support personnel. Creating a staff profile is the first step before an employee can be assigned to teach a class or access the MACSIS portal.

How to Add a New Staff Member

Follow these steps to set up a new staff member in the directory:

  • Navigate to the left-hand menu and click on Staff to open the system directory.
  • Click the + (Plus) icon located at the top right of the screen to open the "Add New Staff" form.
  • Fill out the About section with the employee's official Staff ID, legal First and Last Name, Date of Birth, Gender, and Phone number.
  • Choose an onboarding option under the Mail section. Select "Invite Employee" to have the system automatically send them a welcome email, or select "Add Employee" to simply create their profile in the background using their Mac email. You must provide a valid email address for either option.
  • Complete the Address fields, including Street, City, Province, Postal Code, and Country.
  • Assign system permissions in the Role section. Select their access level using the Role dropdown (e.g., SchoolAdmin), set their Status to "Active," and type in their specific Job Title.
  • Click the blue Submit button at the bottom right to finalize and create the profile.
Figure 1: Add New Staff form illustrating About, Mail, Address, and Role configuration fields.

Navigating the Staff Profile Tabs

Once a profile is created, clicking on an employee's name opens their full Staff Profile. This dashboard is divided into primary tabs located at the top of the screen:

  • Personal Tab: This is the default view. It houses core contact details organized by subtitles, including About, Address, Role, and Placements.
  • Sub-Navigation: On the far left-hand side, beneath the employee's main contact card, a secondary menu tracks academic credentials like "Lectures Taken," "Degree," and "Designation" under About, and specific assigned topics under Subjects.
  • Activity Tab: Click this tab to view a historical log of the staff member's system interactions and engagements.
  • Documents Tab: Click this tab to access the employee's secure file repository.

How to Assign a Teacher to a Class

Once a staff profile is created, you must link that employee to the specific classes they will be teaching:

  • From the main Staff directory, click on a specific employee's name to open their Staff Profile.
  • Ensure you are on the main Personal tab on the right side of the screen.
  • Scroll down past the About, Address, and Role sections to locate the Placements subtitle.
  • Click the blue View Placements link under this subtitle.
  • On the resulting "Place Staff" page, click the Class dropdown menu.
  • Select the specific course (or multiple courses) you want to assign to this instructor.
  • Click the Assign button to lock in the schedule.

2. Building and Managing Classes

The Classes module is the scheduling engine of MACSIS. A class must be fully configured with a designated teacher, room, and capacity limit before any students can be enrolled.

How to Create a New Class

  • Navigate to the left-hand menu and select Classes to view your master schedule dashboard.
  • Click the + (Plus) icon in the top right corner to open the "Add New Class" form.
  • Use the dropdown menus to define core academic details: Grade, Subject, Section, and Period.
  • Select the physical Room assignment and the current academic Year.
  • Type a numerical value into the Limit field. This sets the maximum number of students allowed to enroll before the system flags a capacity warning.
  • Click the blue Submit button to save and activate the class.

How to Quickly Update a Class Capacity Limit

If you need to increase or decrease the size of a class, you can do this directly from the main dashboard without opening the full class profile:

  • Open the main Classes dashboard.
  • Locate the specific class you need to adjust in the roster list.
  • Look for the Limit column (where the current capacity is highlighted by a green, yellow, or red box).
  • Click the small blue pencil icon directly next to the limit number.
  • Type in the new capacity limit and hit enter to save the change instantly.

How to Manage Students Enrolled in a Class

Administrators can easily drop students from a roster or apply material fees directly from a class profile:

  • From the main Classes dashboard, click anywhere on a specific class row to open its full Class Detail page.
  • Review class settings at the top of the page, and locate the Student List table below, which displays everyone currently enrolled in that section.
  • To perform an administrative action, check the empty boxes on the far left side of the table next to the names of the targeted students.
  • Click the Select Action dropdown menu located just above the student list.
  • Choose Unenroll to instantly remove selected students from the class roster, or choose Add Charges to generate a custom bill on their financial accounts.

Frequently Asked Questions (FAQ)

  • What is the difference between "Invite Employee" and "Add Employee" when creating a staff profile?
    Selecting "Invite Employee" automatically sends a welcome email to the user so they can set up their portal access, whereas "Add Employee" creates their profile in the background using their Mac email without sending an automated invitation immediately.
  • How do I adjust a class capacity quickly without opening its profile?
    Navigate to the main Classes dashboard, find the class row, and click the blue pencil icon next to the value in the Limit column to update it inline.
  • Can I assign an instructor to multiple classes at once?
    Yes. When placing staff via the "Place Staff" page, you can select multiple courses from the Class dropdown before clicking Assign.
  • How do I bill students enrolled in a specific class for course materials?
    Open the Class Detail page, check the boxes next to the targeted students in the Student List table, select Add Charges from the Select Action dropdown, and apply the custom bill.
