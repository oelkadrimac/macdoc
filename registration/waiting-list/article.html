Waiting List

Manage students on the waiting list.

By MAC Administration Last updated:

The Waiting List module in MACSIS enables administrators to efficiently oversee prospective students who have applied when classes or grade levels are at capacity. This dashboard helps track waitlist positions, application statuses, and facilitate transitions into active enrollment when spots open up.

How do I access the Waiting List?

To navigate to the waiting list management view:

  • Go to the Student Info section on the dashboard sidebar.
  • Click on Students.
  • Select the Waitlist tab at the top of the student list dashboard.

How do I move an applicant to the Waitlist?

When managing student applications under the Applicants tab, administrators can transition students to the waitlist using the action workflow:

  • Select the target student(s) using the row checkboxes.
  • Choose Move To Wait List from the dropdown menu above the table and click Apply.
  • Review the confirmation prompt outlining the waitlist transfer conditions and click Move To Wait List.

When you move a student to the waitlist:

  • An email with a waitlist-invoice link is sent to the parent.
  • The application status changes to Incomplete until payment is received.
  • Once the parent pays the waitlist fee invoice, the applicant appears under the Waitlist tab.
  • Any previously paid application fee remains non-refundable.

What actions can be performed on the Waiting List tab?

When viewing the Waiting List tab, administrators can select one or multiple student records and use the Select Action dropdown menu above the table to perform various operations:

  • Request Resubmission: Requests corrections or updates from the applicant, transferring the application to the Requested to Resubmit tab.
  • Withdraw: Updates the student status and moves the record to the Withdrawn tab.
  • Download Profile: Exports the applicant's profile details.
  • Download Documents: Downloads all associated student documents in a batch or single file package.

What information is tracked in the Waiting List table?

The waiting list directory organizes applicant records with key tracking columns:

  • Student & Parent Details: Identifies the applicant ID, first name, last name, gender, email, and age.
  • Application Metadata: Tracks the applied date, grade applied for, and payment status.
  • Action Buttons: Quick access tools for viewing notes, editing applicant details, or managing student files.
Note: When a spot opens up and a student is moved from the waiting list to active enrollment, ensure all prerequisite registration checks are completed.
