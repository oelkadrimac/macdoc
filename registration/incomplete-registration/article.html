Incomplete Registration

Manage students with incomplete registration records.

By MAC Administration Last updated:

MACSIS provides dedicated views and workflows for handling applicant records that require missing details, document corrections, or specific paperwork before advancing through the enrollment pipeline.

Incomplete Registrations

When student applications are transferred to the Incomplete section, administrators can review records, track current pipeline steps, and communicate internally.

  • Available Actions: Unlike active workflow stages where records can be directly enrolled, the Incomplete section focuses strictly on review and record tracking.
  • Selecting Records: Use the checkboxes on the left of each row to select individual student records for reference purposes (note that selection is for tracking only, as there are no bulk action tools tied to these checkboxes).
  • Viewing Student Profiles: Click on a Student ID to open and inspect the full candidate profile and submitted details.
  • Adding Comments: Click the comment bubble icon under the Actions column to add or view internal comments regarding why the registration is incomplete or what follow-up is required.

Requested to Resubmit

The Requested to Resubmit tab tracks applications flagged by administration for necessary document corrections, updated files, or missing requirements. It functions as a holding queue where applicants must take action before their file can be re-evaluated for the active enrollment pipeline, allowing administrators to monitor submissions and record specific feedback via internal comments.

Requesting Documents

Administrators can prompt applicants to provide specific missing or additional paperwork directly from a student's profile:

  • Documents Tab: Access the student profile and navigate to the Documents tab.
  • Request Document(s) Function: Use this function to open a modal where you can select the specific files required from the applicant, generating a request that keeps registration files complete and up to date.
  • Tracking Requests: Manage and review the status of these requests centrally under the Requested Documents tab within the Student Info panel, utilizing sub-tabs for Requested, Submitted, and Reviewed.
